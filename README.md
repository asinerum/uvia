# uvia
Python Uvicorn Agent for Native Modules
## Installation
```bash
pip install uvia
```
## Usage
```bash
uvia -m <ASINERUM_UVICORN_SPECIFIC_MODULE> -p <PORT> -c <PEM_CERT_FILE> -k <PEM_KEY_FILE>
```
ASINERUM_UVICORN_SPECIFIC_MODULE might be **xbcc** or **cometchart** or similar Python-based modules.
